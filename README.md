# ⚡ CricPrompt: IPL AI Prompt War Arena

An advanced serverless sports analytics and tactical simulation dashboard engineered for the **GDG Pune Hackathon**. Powered by Google Cloud and Gemini LLMs.

## ✨ Core Architecture Features
* **Dynamic Context Matrix:** Ingests live situational parameters (wickets, required rate, historical bowler-batsman matchups).
* **Prompt War Simulation Engine:** Empowers developers and analytics fans to issue custom tactical prediction strings, challenging Gemini to score realism on a multi-variable calculation vector.
* **Instant Audience Gamification:** Translates structural AI outputs directly into live gamified engagement challenges.

## 🛠️ Google Ecosystem Stack
* **Frontend:** Streamlit Engine (Python-native interface layout)
* **GenAI Orchestrator:** Vertex AI / Gemini API (`gemini-2.5-flash`)
* **Deployment & Containerization:** Google Cloud Run serverless hosting executed natively through **Cloud Buildpacks**.
